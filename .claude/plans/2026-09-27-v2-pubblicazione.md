## Specifiche

- **limits** (`hooks/limits.mjs`, unica fonte, importato da read-guard, session-start, score): `READ_MAX_TOKENS` da `CLAUDE_PLUGIN_OPTION_READ_MAX_TOKENS` (default 10000; valore non numerico o ≤ 0 → default); `SLICE_MAX_LINES` 600; `NATIVE_READ_LINES` 2000; `NATIVE_READ_TOKENS` da `CLAUDE_CODE_FILE_READ_MAX_OUTPUT_TOKENS` (default 25000); `SKIP_EXTS` = l'attuale `BINARY_EXTS` senza `.lock`; `tokens(bytes)` = ceil(bytes/4); costo di una Read cieca = min(token delle prime 2000 righe, `NATIVE_READ_TOKENS`); costo di una slice = stesso calcolo sulle prime 600 righe; directory di log = `CLAUDE_PLUGIN_DATA` o `~/.claude/token-economy`.
- **read-guard**: tool diverso da `Read` → allow; `limit` ≤ 600 → allow; estensione in `SKIP_EXTS` → allow; token stimati dalla dimensione ≤ soglia → allow; altrimenti deny. File mancante o directory → allow (fail-open). Il contenuto si legge solo come prefisso di massimo 2 MB (conteggio righe, mappa, `saved`). `saved` = max(0, costo Read cieca − costo slice − token del messaggio di deny). Messaggio: `Read blocked: "<path>" is ~<N> tokens (<L> lines); whole-file reads are capped at <soglia> tokens. Read the part you need with offset/limit (limit ≤ 600), located via the outline below or Grep.` seguito da `Outline:`; righe omesse oltre i 2 MB.
- **outline**: per `.md`/`.mdx`/`.markdown` gli heading `#`–`###`; per il resto le righe a colonna 0 che iniziano (con prefissi facoltativi `export`, `default`, `pub`, `public`, `async`) con `class`, `def`, `function`, `func`, `fn`, `fun`, `interface`, `type`, `struct`, `enum`, `impl`, `trait`, `module`, `namespace`, `const`, `describe`, `test`. Voce `L<n> <riga troncata a 80 caratteri>`, massimo 30 voci poi `… <k> more`; nessuna sezione se non c'è corrispondenza; oltre i 2 MB la mappa copre solo il prefisso e lo dichiara. Commento `ponytail:` sul limite (scansione a colonna 0, niente parser).
- **telemetria**: record `{ t, project, path, lines, bytes, saved }`, con `project` = `CLAUDE_PROJECT_DIR` o `cwd` del payload o `process.cwd()`; append in `<dir di log>/denied.jsonl`; qualsiasi errore → no-op.
- **explore-router**: matcher `Agent|Task` senza `if`; agisce solo se `subagent_type` è `Explore` (case-insensitive), `model` è assente e l'opzione non è `inherit`; modello da `CLAUDE_PLUGIN_OPTION_EXPLORE_MODEL` (valori validi `haiku`/`sonnet`/`opus`/`fable`, altrimenti `haiku`); output `permissionDecision: "allow"` + `updatedInput` = input originale completo + `model` + prompt con in coda `Report conclusions with path:line references. Do not paste file contents or list every file you opened.`; BOM strippato; ogni errore → exit 0 silenzioso.
- **verifica Explore**: `claude -p` headless con `--model sonnet`, `--settings` che registra solo l'hook router con path assoluto, `--output-format stream-json --verbose`, prompt che chiede di usare Explore per trovare dove è definita `READ_MAX_TOKENS`; esito positivo se i messaggi con `parent_tool_use_id` non nullo hanno `message.model` Haiku e l'input `Agent` originale non conteneva `model`.
- **skill** (inglese): una riga sul principio (ogni risultato resta in contesto); tabella domanda → strumento per capacità, con i nomi grepai come esempi (`compact: true` per localizzare, trace inclusi `grepai_trace_graph`); quando la Read diretta è giusta; delega a `Explore` quando il volume da leggere supera di molto il costo di avvio di un subagent, con template di prompt; consigli per query semantiche con esempi neutri; `grepai_index_status` se i risultati sembrano vecchi. Soglie citate coerenti con `limits.mjs`. `mcp-pruning.md` in inglese: diagnosi con `/context` e `claude mcp list`, tabella degli scope, comandi add/remove/get, template `.mcp.json` grepai con `"command": "grepai", "args": ["mcp-serve"]`, connettori claude.ai gestiti da claude.ai → Settings → Connectors.
